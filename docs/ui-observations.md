# FL Studio desktop interface observations

These observations come from the installed FL Studio 2026 desktop application and a loaded project. They record visible organization and navigation behavior for the clean-room rewrite; they do not define pixel measurements or claim full interface parity.

## Main window

- The main window fills the display and keeps the project name, transport, tempo, elapsed time, and view controls in a narrow top area.
- The top-level menu contains File, Edit, Add, Patterns, View, Options, Tools, and Help.
- FL Studio's File menu shows 10 recent projects and a More list of up to 50, and maps Alt/Option+1–0 to them ([Image-Line File menu](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/menu_file.htm)); the rewrite persists up to 50 paths, exposes the first ten and a More submenu in File, and shows recents in the Browser. The shortcuts pass through the unsaved-change guard.
- Keyboard shortcuts open the Playlist (F5), Channel Rack (F6), Piano roll (F7), and Mixer (F9).
- The Browser occupies a narrow left column. The work area to its right changes between editor views.
- Image-Line's File menu includes New and Exit commands that prompt to save changes ([Image-Line File menu](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/menu_file.htm)). The rewrite now presents Save, Don't Save, and Cancel before opening another project, using File > Exit, or closing the window with unsaved edits.
- Image-Line documents autosave intervals, playback-aware postponement, backup retention, recovery, and sequential Save new version files ([File Search & Browser Settings](https://ww2.image-line.com/fl-studio-learning/fl-studio-online-manual/html/envsettings_files.htm), [File menu](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/menu_file.htm)). The rewrite now offers 5/10/15-minute autosaves or Never. Regular modes pause during playback; Frequent mode saves every five minutes during playback and before plug-in loads, while Very frequent mode saves every minute and before plug-in loads. It keeps a configurable shared set of backups under the user data folder, backs up existing files on manual save, prompts to recover newer autosaves, and provides Backup now, Revert to last autosave, and Ctrl/Cmd+N numbered versions. Opening another project or closing with unsaved edits now prompts Save, Don't Save, or Cancel. Autosave needs a saved project path, and its backup location and file controls still differ from FL Studio.

## Browser

- Image-Line's default Browser tabs include All, Current Project, Plugin Database, Online Content, and Starred (Favorites). The local folder view supports case-insensitive recursive search, and audio files can be previewed ([Image-Line Browser manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/browser.htm)).
- The rewrite now has Files, Project, Plugins, Favorites, and Recent tabs. Files navigates the local filesystem with sample, project, preset, and MIDI filters; FLP files open on double-click and MIDI files enter the import flow. Search filters the visible folder or plug-in/favorites list, while starred paths and up to 30 extra Browser search folders persist in the local config folder. Extra folders can be selected as the current location; Recursive indexes that folder, and All folders indexes supported files under every saved root in one bounded background scan. Both results support name and file-type filters; Ctrl/Command+F focuses the filter and starts the all-roots search, and F3 or Next advances through results. Supported files can carry persistent user tags edited from a # control. Files and Favorites can filter those tags with Any or All matching. Named searches persist the query, file type, folder scope, selected tags, tag logic, and tab style across launches, appear as selectable Browser tabs, and can be renamed, colored, assigned a symbol icon, cloned, hidden/shown, or moved left/right from each tab's context menu. Saving from an active saved tab defaults to that tab's name and style, so its search settings can be updated. Image-Line documents recursive search across Browser folders, Ctrl+F, F3 for the next result, Any/All tag logic, tag editing, saving a search result as a tab, and a 30-folder limit ([Image-Line Browser manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/browser.htm)).
- Image-Line documents a five-second default when clicking Browser audio files, a full-sample option, and a Preview Player that appears when audio is selected ([Browser manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/browser.htm)). The rewrite now auditions supported mono/stereo audio on single-click from Files and Favorites and shows a bottom Preview player with full-sample, Play-to-end, volume, and stop controls; the preview mixes with project output. Tempo/pitch sync, starting at the mouse position, seek/loop controls, broader codec/channel support, drag-and-drop loading, bulk tag editing, native icon assets, and online tabs remain incomplete.
- Image-Line documents loading Browser instrument presets onto Channels and effects onto Mixer tracks or FX slots, including through drag and drop ([Browser manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/browser.htm)). The rewrite opens `.fst` files in a read-only details dialog from double-click or **Inspect preset…**, showing preset kind, header format, FL version, and decoded event/state counts from the lossless document. This dialog is inspection only; applying preset state to a live channel and Browser drag-and-drop loading remain incomplete.

## Channel Rack

- Each channel row combines enable/mute and pan controls, a mixer assignment, a colored channel name, and a step-sequencer lane.
- Instrument, sample, automation, and pattern-linked channels share the rack, while row controls and color vary by channel type.
- A channel's instrument or effect opens in its own floating window; the project observed here had an instrument window over the Channel Rack.
- The Graph Editor opens with Ctrl+K and displays per-step note properties as bars. Left-click and drag edits a bar; right-drag interpolates a ramp across steps; Ctrl adjusts all values together; Alt-click resets values. The documented properties include Note, Velocity, Release, Fine Pitch, Mod X/Y, Shift, Pan, and Rep ([Image-Line Channel Rack manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/channelrack.htm)).

## Playlist

- The Playlist has a timeline ruler, a track-name column, colored clips, and vertical and horizontal scrolling.
- Pattern, audio, automation, and tempo content appear on separate tracks. Track names and clip names can differ.
- The arrangement selector and Playlist tools live in the view toolbar above the timeline.
- The observed project used colored track groups and displayed a long arrangement across more than one hundred bars.
- FL Studio displays audio samples as waveforms inside Playlist clips and offers stereo, combined, and spectral preview modes; its clip view also reflects audio fades and gain previews ([Image-Line Audio Clips manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/playlist_audioclip.htm)). The rewrite now draws a combined min/max waveform for resolved audio-channel clips, crops to source offsets, and scales the visible detail with Playlist zoom. Stereo/spectral modes and fade/gain previews remain incomplete.

## Piano roll

- The left piano keyboard aligns note pitch with a bar-and-beat grid.
- Notes are editable blocks on the grid, with a separate lower control lane for velocity and other note properties. The Select tool (E) supports box selection; Shift adds or removes notes, and Ctrl enables selection while another tool is active ([Image-Line Piano roll manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm)).
- The toolbar above the grid includes drawing, selection, zooming, playback, snapping, and editing tools; the selected channel name appears beside the Piano roll label. FL Studio documents Z-drag to zoom a chosen region, background click to zoom out, Page Up/Down to zoom around the cursor, and Y-click/drag to audition and scrub notes ([Image-Line Piano roll manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm)).
- FL Studio's Piano roll menu exposes Quantize, Quick Chop, Chop, Glue, Arpeggiate, and Strum. Image-Line documents selection-or-whole-roll behavior for many operations; the rewrite's **Auto** target follows that convention, with Channel and Selected notes overrides ([Image-Line Piano roll menu](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll_menu.htm)).
- The reference also lists Select All (Ctrl/Cmd+A), Deselect (Ctrl/Cmd+D), and Invert selection (Shift+I); the rewrite now exposes those commands in a compact Selection menu and supports their shortcuts ([Image-Line Piano roll menu](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll_menu.htm)).
- Image-Line documents Ctrl/Cmd+B to duplicate the selection to the right, or all notes when no note selection exists; its time selection can override the repeat interval. The rewrite now duplicates the selected notes, or all notes in the target channel, by the copied notes' total time span. It does not yet support an independent time selection or custom repeat interval ([Image-Line Piano roll manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm)).
- Image-Line's lower Piano roll editor displays note velocity, pan, release, pitch, and modulation properties, selected through its Target control; Shift+F cycles targets. The rewrite's **Events** panel now draws per-note stems for velocity, pan, release, fine pitch, Mod X, and Mod Y, with draggable values. It does not yet edit pattern-scoped controller automation or provide native interpolation and scale behavior ([Image-Line Piano roll manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm)).
- Image-Line's Chord Stamp places chords at the clicked pitch and time, follows snap and scale settings, and includes one-use behavior. The rewrite now has a Stamp mode with manual chord qualities and scale-derived triads/sevenths; its current UI does not yet include automatic top-down/bottom-up voicing, voice leading, pattern presets, or chord preview ([Image-Line Piano roll manual](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/pianoroll.htm)).

## Mixer

- Mixer inserts are displayed as vertical strips with color, names, pan controls, volume faders, meters, and routing controls.
- The selected insert exposes ten effect slots in a right-side panel, with equalizer controls below.
- The observed project used many named, color-coded inserts and several effects per insert.
- Image-Line documents a selectable track bank and a Track Inspector that exposes track properties and up to ten effect slots per track ([Mixer Explained](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/mixer.htm), [Effects Slots](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/mixer_plugin.htm)). The rewrite now displays recognized inserts as selectable vertical strips and shows the selected insert's editable name and preserved raw fields in an inspector. It lists ten disabled effect-slot placeholders while the slot data remains opaque. Its expandable project-wide `0xE1` list can edit signed values by event and record index, and labels target/slot fields as candidates. Effect identity/state, faders, meters, and native track-number mapping are not decoded yet.

## Current rewrite gap

The Rust shell currently places the Browser and one editor view inside a single application window. Its Playlist, Channel Rack, Piano roll, and Mixer remain simplified views. The Mixer now shows recognized insert records as selectable vertical strips with a focused inspector for existing names and raw fields; faders, meters, effect slots, and track routing remain incomplete. The Channel Rack implements a Ctrl/Cmd+K Graph Editor for note key, velocity, pan, release, fine pitch, modulation X/Y, and shift; it also supports right-drag ramps. Note-repeat bars, Ctrl scale-all, Alt reset, multiple notes at one step, and native window behavior remain incomplete. The Piano roll can create a note by double-clicking the grid, select notes with its Select tool or modifier gestures, move or resize a selected group together, delete a selection while preserving unrelated FLP event bytes, and zoom by dragging a region or using Page Up/Down around the cursor. Quantize can target a whole channel or only the selected notes; the Edit target selector routes Legato, Chop, Glue, Flip, Strum, Flam, Randomize, Humanize, Limit, Arpeggiate, and Slice to the whole channel or current selection. Playback (Y) auditions Sampler or loaded VST3 notes on click and while dragging across note blocks; native instrument preview and continuous playhead scrubbing remain incomplete. Note movement and resizing follow the selected snap value, including bar length derived from the project time signature. Mute remains incomplete because its FLP note-flag encoding has not been established. Native toolbar and window behavior also remain incomplete. MIDI import can load a file, select a track, and append its notes to the selected pattern and channel after converting PPQ. VST3 editor windows are hosted. For recognized VST project state, the Plug-ins view shows the decoded name, vendor, and class UID, suggests an installed bundle match, and offers a state-load attempt. A successfully loaded project-matched VST3 is associated with its FLP channel: the Channel Rack shows its decoded name and enables that channel's editor control. Opening an already loaded editor recreates its floating window to bring it to the foreground. The Piano roll can render its selected pattern/channel to WAV through a loaded VST3. This render does not yet expand Playlist clips or apply project Mixer routing/effects. Exact state restoration, other VST formats, Image-Line wrapper behavior, native FL plug-in windows, clip tools, menus, transport behavior, advanced note draw tools, and other channel controls still need reverse engineering and implementation.
